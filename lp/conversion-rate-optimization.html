Conversion rate optimization for small business websites

If you downloaded my 'Website Foundations' checklist, you already fixed all of the technical aspects of your small business website (speed, accessibility, security and privacy).

If not, grab it now, and first go through the basics. Just follow the short weekly tutorials you'll get in your email inbox.

Now we need to look at all of the individual parts of your website, and optimize them for conversion. Because each of those small improvements contribute to the overall increase of your website's conversion rate.

We'll start with the parts of your website that most visitors see immediately after webpage loads (at the top of the page), then we'll discuss parts that only highly engaged visitors come across.

1. Navigation

Website navigation is usually the first thing we encounter, given the fact that it's on the very top of every webpage. Besides, we're all used to checking the navigation to see what's available on a website. Makes sense to optimize this section of your small business website first. Here's how:

<
  • Keep it simple - limit the menu items to the most important webpages. Otherwise you risk overwhelming the users of your small business website. Everything else can be placed somewhere else on the page (for example in the footer section).
  • Make it intuitive - use clear (self-explanatory) labels, and don't be misleading. First and last items in a list are usually most memorable to people, so use it to your advantage.
  • Check if the menu behaves as expected, especially on smaller screens. Keep in mind that the web browsing on mobile devices is ever increasing.

In most use cases I recommend using a sticky header section, since it makes the navigation easily accessible even when scrolling webpages with longer content.

If you're using WordPress for your small business website, you can use one of the many (free) plugins to make a sticky header. But since I prefer using Kadence theme, you can set it up in through the theme customizer. You can check that WordPress theme here:
https://wordpress.org/themes/kadence/ [Check the image below]

The default navigation block in WordPress is a good starting point to build out your website navigation. It makes the vertical menu transform into drop-down menu on smaller screens. [Check the image below]

But the features are basic, so if you need something more advanced, I recommend using a free plugin - Kadence Blocks (complementary to Kadence theme, but can be used separately). Check out the plugin features here:
https://wordpress.org/plugins/kadence-blocks/ [Check the image below]

Among other things, this plugin enables you to make templates for your navigation, that can consist out of other blocks. This allows you to add advanced functionality like website search.

2. Search

For any website with a lot of content, it's necessary to have a good search functionality. It doesn't matter if it's just blog posts, or a bunch of products on e-commerce store. And we know that a small business with limited marketing budget needs a decent content library for organic reach.

Now let's talk about the search feature best practices:

  • Place the search feature in usual location (in the header section), so users can find it instantly.
  • Allow users to filter the search results, especially if you have a lot of different categories of posts or products.
  • Provide real-time suggestions and popular search terms to guide users while they're typing. This reduces typos or dead ends.
  • Search results need to be visually appealing, with clear images, prices, and CTAs, not just plain links. Reduce the steps needed for them to take the desired action.
  • Make sure you handle the “no results” scenario by suggesting similar categories of products or content, and keep the users engaged.
  • Check the data on search queries - if people are often searching for something you don't offer, you can consider adding it to your offer.

If you're using WordPress for your small business website, it's easy to add the search feature - it's available by default as a block you can add in the block editor. [Check the image below]

But this search functionality is basic, and it doesn't go through all of the advanced data types used in WordPress.

That's why you'll probably need a WordPress plugin for advanced search features - like faster AJAX search, and search analytics.

I recommend a good free option:
https://wordpress.org/plugins/add-search-to-menu/ [Check the image below]
